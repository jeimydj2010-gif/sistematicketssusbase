Conectar Supabase de pruebas

Esta pantalla evita que el proyecto use accidentalmente la base de producción.

Importante: usa la Project URL y la Publishable/Anon key del proyecto Supabase de pruebas. Nunca pegues la service_role.

Instalación de base: ejecuta primero schema.sql en Supabase SQL Editor.

Datos de prueba: luego ejecuta los SQL de la carpeta sql_datos_prueba_divididos en orden.

La configuración guardada aquí queda solo en este navegador. Para todos los equipos, edita supabase-config.js y coloca allí la URL y la clave de pruebas.
